Stress Detection

On the physiological table this model was trained on, tree ensembles sit around 98%. The interesting part is how little they differ.

Physiological signalsLightGBMNotebook

Question

  • Can heart rate, skin response, and the rest of this sensor table separate stressed from calm?

Method

  • The same cleaned table goes to logistic regression, random forest, XGBoost, and LightGBM.
  • F1 and ROC-AUC, not accuracy alone, because the decision has a cost.

Evidence

~98%forest, XGBoost, and LightGBM
~93%logistic regression
3models within one point

What the result actually says

  • Logistic regression is about 93%. Random forest is about 98.2%, LightGBM about 98.3%, XGBoost about 98.4%.
  • F1 for the tree models stays above 0.98. The ROC curves are in the notebook, so the ranking is visible without retraining.
  • The three ensembles are within a point of each other. LightGBM or random forest is the practical choice because they train faster.

What it does not show

  • The physiological table this was trained on is local. It is not in the GitHub repo, so a fresh machine cannot rerun training from the clone alone.
  • Accuracy this high on one sensor table does not say the same model would hold on a different device or a different labeling protocol.

Beside the other attempts

  • The linear model is the one that falls behind. Adding another boosting library does not move the result.
